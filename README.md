# Lines 98

A browser version of the classic Lines 98 ball game. Plain HTML/CSS/JS with no build step.

Play: https://mariuspaukste.github.io/lines-98/

## How to play
Move a ball to any empty cell it can reach. Line up 5 or more balls of one colour (across, down or diagonally) to clear them. If a move clears no line, 3 new balls appear. The game ends when the board fills up.

Small dots on the board show where the next 3 balls will land. Tap the next-balls box at the top to turn these hints on or off; the setting is remembered.
